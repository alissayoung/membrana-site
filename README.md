# Мембранный транспорт

Учебный сайт по биологии, 11 класс, глава 3, §16–17: «Типы транспорта веществ через клеточную мембрану» и «Механизм активного транспорта ионов на примере натрий-калиевого насоса».

## Страницы

- `index.html` + `app.js` — главная с вкладками внизу: §16 Типы, §17 Насос, Игра, Справочник, Вопросы. В центре частицы собираются в иллюстрацию раздела; на вкладке насоса они превращаются в анимацию цикла Na⁺/K⁺-АТФазы.
- `spravochnik.html` — справочник: 11 статей с пошаговым разбором процессов и словарь терминов.
- `game.html` — мини-игра «Пройди мембрану»: играй за натрий, калий или АТФ (`game.html?hero=na|k|atp`).
- `konspekt.md` — конспект по материалам сайта.

Статический сайт без сборки: HTML, CSS и JavaScript без библиотек. Шрифт — Inter Tight из Google Fonts. Вкладки доступны по ссылкам вида `index.html#pump`.

## Запуск локально

Открой `index.html` в браузере.

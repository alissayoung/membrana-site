# Мембранный транспорт

Учебный сайт по биологии, 11 класс, глава 3, §16–17: «Типы транспорта веществ через клеточную мембрану» и «Механизм активного транспорта ионов на примере натрий-калиевого насоса».

## Страницы

- `index.html` — главная: анимация цикла Na⁺/K⁺-насоса, классификация видов транспорта, цикл насоса, тест из 6 вопросов.
- `spravochnik.html` — справочник: 11 статей с пошаговым разбором процессов и словарь терминов.
- `game.html` — мини-игра «Пройди мембрану»: играй за натрий, калий или АТФ.
- `konspekt.md` — конспект по материалам сайта.

Статический сайт без сборки: HTML, CSS и JavaScript без библиотек. Шрифт — Inter Tight из Google Fonts.

## Запуск локально

Открой `index.html` в браузере.
